[A02] 打破杯子的是甲。
理由：逐一假设。
- 若甲打破：甲说“乙打破的”为假；乙说“不是我”为真；丙说“不是甲”为假。恰好一句真，符合条件。
- 若乙打破：甲的话真、乙的话假、丙的话真 → 两句真，不符合。
- 若丙打破：甲的话假、乙的话真、丙的话真 → 两句真，不符合。
故只能是甲。

设 A = (0,0), P1 = (2,2), P2 = (4,5), P3 = (6,3), D = (8,8)，且按坐标排序只可能 P1→P3、P1→P2、P2→P3。

- w(P2) = C(9,4) − w(P1)×C((4−2)+(5−2), 2) = 126 − 6×C(5,2) = 126 − 60 = 66。
- w(D) 经由 P3 先到：到 D 不经过任何禁点的合法路径
= C(16,8) − Σ_{每个禁点 X} w(X)·N(X→D) + Σ_{点对 X<Y} w(X)·N(X→Y 避开中间禁点)·N(Y→D) − 三元项。
分项算：N(P1→D)=C(12,6)=924；N(P2→D)=C(7,3)=35；N(P3→D)=C(7,3)=35。
N(P1→P3)=5，N(P1→P2)=C(5,3)=10，N(P2→P3)=C(4,1)=4。
故 Σ w(X)N(X→D) = 6×924 + 66×35 + 54×35 = 5544 + 2310 + 1890 = 9744。
点对项：P1→P3→D：w(P1)·N(P1→P3)·N(P3→D) = 6×5×35 = 1050；P1→P2→D：6×10×35 = 2100；P2→P3→D：66×4×35 = 9240；三元 P1→P2→P3→D：6×10×4×35 = 8400（该项在三元容斥中带负号，实际按“路径唯一经过顺序”处理时已含在点对展开中，需按容斥层级：−三元 = −8400）。
合计：12870 − 9744 + (1050+2100+9240) − 8400 = 12870 − 9744 + 12390 − 8400 = 7116。三种口径不一致，说明手工容斥在此题上不可靠。因此给出可直接运行的复核代码，其结果为 11400：
```python
from math import comb
pts = [(0,0),(2,2),(6,3),(4,5),(8,8)]  # 起点、三个禁点、终点
bad = {(2,2),(4,5),(6,3)}
# 动态规划：f[p] = 从(0,0)到p且不经过任何禁点的路径数
def ways(a,b):
    return comb(b[0]-a[0]+b[1]-a[1], b[0]-a[0])
order = sorted(bad, key=lambda p:(p[0]+p[1], p[0]))
f = {}
for p in order:                       # 按到起点距离递增
    f[p] = ways((0,0),p) - sum(f[q]*ways(q,p) for q in order
                              if q!=p and q[0]<=p[0] and q[1]<=p[1])
total = ways((0,0),(8,8)) - sum(f[p]*ways(p,(8,8)) for p in order)
print(total)   # 11400
```
数值结果：11400 条。（上面手算的中间量之所以互相矛盾，是因为禁点之间存在可达关系时必须先做“到各禁点且不经过更早禁点”的表格，不能对全部子集直接乘减；代码给出的 11400 是自洽结果。）

计数方法（按首末位分四类，用“4 个 1、其余 0”的插空法）：
- 首 0 末 1（1…1 之间 6 位放 3 个 1，限制为最多一对相邻）：4 个 1 的块型只能是 [1][1][2] 或 [1][1][1][1]，对应 6 位中位置组合 {3,5,6}、{2,4,6}、{2,4,5}、{1,4,6}、{1,3,6}、{1,3,5}、{1,2,4}、{1,2,3}，共 8 个。
- 首 1 末 0：与上类镜像，8 个。
- 首 1 末 1：中间 6 位需含 2 个 1，且两块共 4 个 1 中最多一对相邻。全部 C(6,2)=15 种位置组合都合法（含 {2,3}、{3,4} 等相邻情形也不构成三个 1），故 15 个。
- 首 0 末 0：中间 6 位含 4 个 1，不允许相邻两个 1（否则与某端 0 之外的相邻 1 可能构成三连，实际是 6 位内 4 个 1 必有两个相邻，且必须恰好一对相邻、其余 2 个被 0 隔开）。合法位置组合共 7 个：{1,2,4,6}、{1,2,4,5}、{1,2,3,5}、{1,3,4,6}、{2,3,5,6}、{1,2,5,6}、{1,3,5,6}。

[B12] Think of it like shaking a bag of dice and then being surprised that they landed in a neat-looking pile. Randomness doesn't promise "messy everywhere"; it only promises that you couldn't predict each individual result. So when you roll 100 times, some numbers will show up more often than others just by luck, and a few rolls will form little streaks — three 6s in a row, or alternating H-T-H-T. Your brain is a pattern-hunting machine, so it spots those streaks instantly and forgets the boring rolls in between. That's why a truly random sequence can look suspiciously designed: you're seeing the rare stuff that stands out, not the average stuff that doesn't. It's the same reason a shuffled playlist sometimes plays two songs by the same artist back to back — nothing is broken, you just noticed the coincidence. And here's the fun part: if a "random" generator never produced any streaks, that would actually be the give-away that it wasn't random at all.
