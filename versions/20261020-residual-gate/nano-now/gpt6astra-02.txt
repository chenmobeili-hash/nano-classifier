[A11]
共有 **3882条**。

用容斥原理。经过某个点的路径数，等于到达该点的路径数乘以从该点到终点的路径数。不加限制时有\(\binom{16}{8}\)条。

经过三个禁点的路径数分别为：
\[
\begin{aligned}
N_{(2,2)}&=\binom42\binom{12}{6}=5544,\\
N_{(4,5)}&=\binom94\binom74=4410,\\
N_{(6,3)}&=\binom93\binom72=1764.
\end{aligned}
\]
同时经过两禁点的路径数为：
\[
N_{(2,2),(4,5)}=6\times10\times35=2100,
\]
\[
N_{(2,2),(6,3)}=6\times5\times21=630.
\]
只能向右、向上，因此不可能同时经过\((4,5)\)和\((6,3)\)，也不可能经过全部三个禁点。故答案为
\[
12870-5544-4410-1764+2100+630=\boxed{3882}.
\]

[A12]
共有 **26个**。

先算首位为0、末位为1的情况。若有\(k\)段连续的1，就也有\(k\)段连续的0。每段1只能长1或2，而4个0分成\(k\)个非空段有\(\binom{3}{k-1}\)种方法。

- \(k=2\)：1段长度只能为\((2,2)\)，共\(1\times3=3\)种。
- \(k=3\)：1段长度为\((2,1,1)\)的排列，共\(3\times3=9\)种。
- \(k=4\)：各段均长1，共1种。

合计13种。反转字符串可一一对应到首位为1、末位为0的情况，因此总数为\(13\times2=26\)。

[B08]
平均数只告诉你数据的平均水平，没有告诉你数据分布得有多散。

比如两组人的等待时间分别是“5、5、5分钟”和“0、0、15分钟”，平均都是5分钟。但第一组每个人的体验都一样；第二组两个人完全不用等，一个人却等了很久。

所以，要了解实际情况，还需要看数据之间的差异、有没有特别大的或特别小的数，以及多数数据集中在哪里。

[B12]
Randomness can produce patterns because it doesn’t have a rule against them. When you flip a fair coin, getting four heads in a row doesn’t make tails “due.” The next flip still has a fifty-fifty chance.

Over a long sequence, you have many opportunities to see streaks, repeated blocks, or surprisingly neat alternations. A sequence that never allowed those patterns would actually be constrained: each new result would have to avoid certain earlier results.

Most computer simulations use a deterministic algorithm to generate numbers that behave like random draws. A good simulation can therefore contain noticeable patterns without anything being wrong. The useful question is whether a pattern occurs more often than the model predicts—not simply whether you can spot one.
